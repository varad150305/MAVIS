# MAVIS: one Python 3.11 environment for the hub, MAVIS OCR and the gesture controller.
#
#     py -3.11 -m venv .venv
#     .venv\Scripts\python -m pip install --no-deps -r requirements-lock.txt      (setup.bat does this)
#
# How the two projects' requirements were combined:
#   * MAVIS's full lock file (modules/mavis/requirements-lock.txt) is kept, version for version, EXCEPT:
#       opencv-python-headless==4.8.0.76  ->  opencv-contrib-python==4.8.0.76
#     Same OpenCV version; the contrib build contains everything headless has, and it is what MediaPipe depends on.
#     Both projects warn that two OpenCV packages in one environment overwrite each other, so exactly one is installed.
#   * The gesture controller's pins: mediapipe==0.10.21 (needs mp.solutions; Python 3.9-3.12), numpy<2 (MAVIS's 1.26.4).
#     The gesture README asks for Python 3.12; MediaPipe 0.10.21 also ships Python 3.11 wheels, and MAVIS is verified on
#     3.11 only, so the suite uses 3.11. The gesture project's 112 tests pass in this environment.
#   * MediaPipe's other declared dependencies jax, jaxlib, sentencepiece and sounddevice are not used by the hand tracker
#     and are not installed (--no-deps). matplotlib IS needed (MediaPipe's drawing utilities import it).
#   * Hub additions: cryptography (HTTPS certificate for phones), segno (QR code).
#
