# Drop real test images here

`compare_modes.mjs` reads every `.jpg`/`.jpeg`/`.png`/`.webp` file directly in
this folder (not subfolders). Per research/README.md's own rule: real photos
only, ideally licensed for use — nothing synthetic or AI-generated, since the
whole point is measuring real-world accuracy.

Good candidates, matching Drishti's actual target scenarios (see
ARCHITECTURE_AUDIT.md): an indoor hallway with furniture, an outdoor street
with pedestrians/vehicles, a printed sign or product label, an Indian
currency note, a crosswalk.
