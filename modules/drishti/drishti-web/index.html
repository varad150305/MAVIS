📱 Use your phone as camera

Option A — EpocCam (recommended, free 480p)
  1. Install EpocCam on iPhone
  2. Install EpocCam Windows driver
  3. Same Wi-Fi → open EpocCam on iPhone → click Start Camera → pick EpocCam
Option B — iVCam (better quality)
  1. Install iVCam on iPhone + iVCam PC client
  2. Same Wi-Fi → both open → select iVCam in camera picker
Option C — Open Drishti on your phone directly

Run ipconfig → copy IPv4 → run npx serve . in this folder → open http://YOUR_IP:PORT in iPhone Safari
